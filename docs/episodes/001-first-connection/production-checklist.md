# Production checklist

Use this as the only detailed status list for the episode. Keep tasks small and actionable; remove anything that does not apply.

## Shape the story

- [ ] Confirm the premise and central question.
- [ ] Gather the sources needed for the story.
- [ ] Draft and revise the Persian script.
- [ ] Prepare and review the English translation.

## Make the episode

- [ ] Decide which audio and visuals are actually needed.
- [ ] Record narration.
- [ ] Edit and review the episode.
- [ ] Check names, facts, translation, and asset rights.
- [ ] Write a short ending with a final reflection, next-episode preview, and contribution invitation (about 30 seconds total).

## Release

- [ ] Prepare cover, description, and captions if needed.
- [ ] Add the [contribution guide](../../contributing.md) link to the video description.
- [ ] Approve the final export.
- [ ] Publish and add date/link to `episode-brief.md`.

[Write the single next action, or `None` when ready/published.]
