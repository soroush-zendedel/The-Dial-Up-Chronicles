# Episode template

Copy this folder to `episodes/NNN-short-title/` and replace the placeholders. Keep what helps; delete sections that do not apply. The checklist is the episode's single progress tracker.

## Files

- `episode-brief.md`: premise, status, and release details.
- `production-checklist.md`: next actions and completion state.
- `languages/fa/script.md` and `languages/en/script.md`: independent language versions.
- `research-and-sources.md`: story-relevant sources and fact checks.
- `audio/audio-cue-sheet.md`: sounds actually used or planned.
- `visuals/visual-plan.md` and `cover-art-prompt.md`: visual plan and prompt when needed.
