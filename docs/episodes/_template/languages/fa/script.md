# متن فارسی

> وضعیت: پیش‌نویس

## متن

[متن روایت را اینجا بنویسید.]

## پایان

### تأمل پایانی

[یک جمله برای نشستن روایت؛ نتیجه‌گیری اجباری نکنید.]

### پیش‌نمایش قسمت بعد

[در یک جمله بگویید قسمت بعد به چه موضوعی می‌پردازد؛ اگر هنوز معلوم نیست، این بخش را موقتاً حذف کنید.]

### دعوت به مشارکت

اگر پیشنهادی برای این پروژه دارید، آن را به Codex بگویید؛ پس از بررسی تغییر، از Codex بخواهید آن را برای بررسی به پروژه بفرستد. راهنمای کوتاه در توضیحات این قسمت است.
