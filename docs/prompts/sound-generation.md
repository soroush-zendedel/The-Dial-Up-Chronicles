# Sound generation prompts

Use a separate prompt record from `assets/templates/prompt-record.md` for each reusable generated sound. Capture the exact prompt and the sound-generation tool or agent, version, date, selected output, and rights check.

## Direction

Create subtle, short, clean sound textures such as a distant dial-up connection, quiet keyboard typing, or a restrained messenger notification. Keep sounds low-key, non-startling, and suitable under speech. Do not recreate a protected recording or imply that a generated sound is an authentic archival recording.
