# Music generation prompt

Reusable starting point for the show's opening theme. Adapt and record specific runs in a dedicated asset record if this becomes an active production item.

- **Version:** v1
- **Status:** Draft

## Prompt

Create a restrained, original late-night podcast opening theme for a reflective documentary about the early web and personal memory. The voice must remain the focus. Use a sparse, warm, slightly nostalgic texture with a slow pace and a clear ending that can transition into narration. Avoid dramatic rises, busy percussion, recognizable melodies, and imitating existing artists or copyrighted works. Provide a clean instrumental version and state the exact duration.

## Generation record

Record the tool/model and version, agent if used, date, selected output location, applicable terms/rights review, and episodes using the final track in the asset record under `assets/music/`.
