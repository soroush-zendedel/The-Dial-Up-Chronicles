# Decision 0001: Keep production planning lightweight

- **Status:** Accepted
- **Date:** 2026-10-24

## Decision

Use English filenames and shared project documentation, Markdown-first records, one copyable episode template, and separate language folders for each script and translation. The initial languages are Persian (`fa`) and English (`en`).

Track progress in the episode checklist and keep supporting records only when they help production, rights review, or future reuse. Keep unlicensed and bulky working media out of Git. Version prompts in Git and record the tool, version, date, and selected result when relevant.

## Reason

The repository should make planning and production easier to coordinate without making planning heavier than making the show.
