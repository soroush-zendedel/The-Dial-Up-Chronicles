# Lightweight production workflow

Use the episode checklist as the working status record. Skip or remove steps that do not apply.

1. **Choose:** Write the episode's central question and why it matters now.
2. **Gather:** Save a few useful sources and separate verified context from personal memory.
3. **Write:** Draft and revise the Persian script; make the English translation when the Persian version is stable enough to translate.
4. **Plan the sound and picture:** Note only cues, assets, and visuals that will actually be used.
5. **Record and edit:** Work with local media files; keep large raw files outside Git.
6. **Review:** Check the story, names, translations, rights, and final export.
7. **Publish:** Record the release date and links in the episode brief.

Planning is successful when it removes uncertainty from the next production step. If a document is not helping, simplify it.
