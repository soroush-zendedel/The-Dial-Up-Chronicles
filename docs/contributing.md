# Contribute to the project

The easiest contributions are specific corrections, source suggestions, translation notes, and ideas for future episodes. You do not need to edit audio or upload media to suggest an improvement.

## Suggested workflow

1. Create a GitHub account and install [GitHub Desktop](https://desktop.github.com/).
2. Open the [project repository](https://github.com/soroush-zendedel/The-Dial-Up-Chronicles) and choose **Fork** to make your own copy. This gives Codex a place to send your proposal without changing the main project directly.
3. In GitHub Desktop, choose **File → Clone repository** to download your fork, then open that folder in Codex.
4. Tell Codex what you would like to change and why. Ask it to make the edit, explain the result, and show you the changes for review.
5. When you are happy with the result, tell Codex to commit the change, push it to your fork, and open a pull request for the project. Codex can handle those Git steps; review the pull request details before it is sent.

Example request to Codex: “Please make this change in the project, show me the diff, and explain what you changed. After I review it, commit it to my branch, push it to my fork, and open a pull request with a short explanation.”

## Keep contributions useful

- Make one focused suggestion at a time and explain its source or reasoning.
- Mark memories, interpretations, and verifiable historical claims clearly.
- Do not upload copyrighted audio, images, or other material unless you have permission to share them.
- Do not include private information about yourself or other people.

You can also ask Codex to open an issue if you would rather describe an idea than edit files. Suggestions are welcome; a pull request is reviewed before it is merged.
