# Contribute to the project

The easiest contributions are specific corrections, source suggestions, translation notes, and ideas for future episodes. You do not need to edit audio or upload media to suggest an improvement.

## Suggested workflow

1. Create a free GitHub account and install [GitHub Desktop](https://desktop.github.com/).
2. Open the [project repository](https://github.com/soroush-zendedel/The-Dial-Up-Chronicles) and choose **Fork** to make your own copy.
3. In GitHub Desktop, use **File → Clone repository** to download your fork to your computer.
4. Open the cloned project folder in Codex. Ask it to make one clear, small change, such as correcting a fact, suggesting a source, or improving a translation. Tell Codex which file and why; review its proposed changes before accepting them.
5. In GitHub Desktop, review the changed files, enter a short commit summary, and select **Commit to your branch**. Then choose **Push origin** to upload the commit to your fork.
6. On GitHub, choose **Contribute → Open pull request** and explain what you suggest and why. The project owner can review it before it becomes part of the project.

## Keep contributions useful

- Make one focused suggestion at a time and explain its source or reasoning.
- Mark memories, interpretations, and verifiable historical claims clearly.
- Do not upload copyrighted audio, images, or other material unless you have permission to share them.
- Do not include private information about yourself or other people.

You can also open an issue on GitHub if you would rather describe an idea than edit files. Suggestions are welcome; a pull request is reviewed before it is merged.
