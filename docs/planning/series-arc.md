# Series arc

## Current shape

The series follows a personal path through the changing web: first encounters, communities and tools, learning by exploration, and the values that carry into today's work as an engineer and independent maker.

This is a flexible direction, not a commitment to a fixed season order. Add episode ideas when a specific memory or question emerges.

## Pilot

The first connection in Zabol and the search for a shared language in Yahoo chat rooms.
