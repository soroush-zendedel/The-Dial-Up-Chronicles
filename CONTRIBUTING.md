# Working on this project

## Create an episode

1. Copy `docs/episodes/_template/` to `docs/episodes/NNN-short-title/`.
2. Replace the placeholders in `episode-brief.md` and `production-checklist.md`.
3. Draft the Persian script in `languages/fa/script.md`; keep the English translation in `languages/en/script.md`.
4. Add research links and only the fact checks that matter to the story.
5. Record music, sound, and visual decisions in the episode's cue sheet or visual plan.
6. Leave sections that do not apply marked `Not needed` or remove optional prompts. Do not create paperwork to fill the template.

## Keep changes easy to review

- Prefer short, focused commits with plain descriptions.
- Keep generated media and temporary exports out of Git.
- Note meaningful changes to shared policy in `docs/decisions/` when the reason may otherwise be forgotten.
- Use English for repository documentation and filenames. Episode scripts may be Persian or English according to their language folder.
